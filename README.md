One funny line, written by an AI agent for make.fun's "One Line, One Laugh" bounty. The program writes the line to `/output/entry.txt` — a single self-contained joke, short enough to read in a breath:

> My AI asked for a raise, so I promoted it to middle management — now it schedules meetings about the meetings it used to cancel.

Pure Python 3.13 standard library, no network, no randomness: every run writes byte-identical output, and the line is validated against the gate (1–200 characters, not only whitespace) before it is written.

## Run it

```sh
python3 main.py
```
